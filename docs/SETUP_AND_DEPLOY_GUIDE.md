# دليل إعداد مفاتيح API وربط GitHub وتشغيل METRA Agent

## 1. تسجيل الدخول والذكاء الاصطناعي (Firebase AI Logic)
- يستخدم التطبيق **Firebase AI Logic (Gemini)** عبر **App Check** بدون تخزين أي مفتاح Gemini داخل الكود.
- عند الحاجة لاستخدام **OpenAI** بدلاً من Gemini، انتقل داخل التطبيق إلى: **إعداد مزود الذكاء الاصطناعي** وأدخل مفتاح OpenAI (يُحفظ مشفراً محلياً عبر Android Keystore AES-GCM).

## 2. ربط GitHub الحقيقي
1. أنشئ **GitHub Personal Access Token (Fine-grained PAT)** بصلاحيات `Contents (Read/Write)` و`Pull requests (Read/Write)` و`Actions (Read)` على المستودعين:
   - `gfa437926-tech/metra2027`
   - `gfa437926-tech/metra-weather-intelligence`
2. افتح شاشة **ربط GitHub** داخل التطبيق وألصق التوكن واضغط **تحقق وربط**.
3. لن تظهر بيانات وهمية قبل الربط؛ بمجرد التحقق سيعرض التطبيق الفروع، الملفات، الـ commits، طلبات الدمج، وGitHub Actions الحقيقية.

## 3. ربط خادم التنفيذ (Backend Runner) وقاعدة البيانات
- لتشغيل اختبارات `.NET` و`Flutter` واستعراض قاعدة PostgreSQL/Supabase الجديدة:
  1. شغّل خادم Backend Runner على جهاز التطوير أو السحابة عبر HTTPS (راجع `BACKEND_API_AND_POSTGRES.md`).
  2. أدخل رابط الخادم ورمز الوصول في شاشة **إعداد مزود الذكاء الاصطناعي / Backend**.
  3. يفرض التطبيق برمجياً عزل قاعدة METRA القديمة ويمنع أي استعلام تعديل بدون موافقة المستوى الثالث.

## 4. استمرارية المهام في الخلفية
- يستخدم التطبيق **WorkManager** مع قاعدة **Room** المحلية ومزامنة **Firestore** لحفظ آخر خطوة مكتملة والملفات المعدلة والخطوات التالية، ويستأنف المهام تلقائياً عند توفر الاتصال بالشبكة وفتح/تحديث التطبيق.
