# التخزين متعدد المصادر — AI I.Z

فرع: `feature/multi-source-project-storage` (من `4205223`).

## المبادئ

1. **محلي أولاً:** حفظ/فتح/حذف المشاريع يعمل دون إنترنت ودون تسجيل دخول ودون PostgreSQL/Backend.
2. **AI سحابي:** توليد الكود عبر مزودي السحابة يحتاج شبكة؛ النماذج المحلية مسار منفصل مستقبلي.
3. **موفرو السحابة (Google Drive / OneDrive / Dropbox):** واجهة موحّدة + تخزين رموز OAuth في SecretVault فقط. **لا يُدّعى نجاح المزامنة السحابية قبل اختبار حساب حقيقي.**
4. **Backend AI I.Z:** مرآة اختيارية عند وجود جلسة؛ فشله لا يمنع الحفظ المحلي.
5. **Google Sheets:** ليس مخزن ملفات؛ أي تكامل جداول لاحق اختياري للتقارير فقط.

## الإصدارات والتعارض

- كل حفظ محلي يزيد `revision` ويحتفظ بنسخ تحت `versions/`.
- عند تعارض التعديلات: سياسة افتراضية `KEEP_BOTH` (نسخة تعارض منفصلة دون فقد الحالية).

## الرموز

لا تُضمَّن أسرار OAuth في APK. تُخزَّن access/refresh في الخزنة المشفّرة بعد تدفق OAuth الرسمي (يُستكمل ربط الحساب الحي خارج هذا الالتزام إن لزم).
