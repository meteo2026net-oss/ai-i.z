## تعليمات الاستخدام
1. افحص التطبيق الحالي قبل التعديل.
2. اعتبر الشفرة الحالية مصدر الحقيقة للتقنيات والوظائف الموجودة.
3. ادمج الوثائق دون تكرار أو تعارض صامت.
4. لا تغيّر التقنية أو قاعدة البيانات أو النطاق دون اعتماد المستخدم.
5. نفّذ العمل الفعلي واختبره؛ لا تكتفِ بإنشاء وثائق أو واجهات شكلية.
6. سجّل المنجز والمتبقي والأدلة والعوائق بوضوح.
